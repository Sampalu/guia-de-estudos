Builder

Separar a construção de um objeto complexo de sua representação, de modo que o mesmo processo de construção possa criar diferentes representações.

Builder - Creational (Criação)

Intenção

Separar a construção de um objeto complexo da sua representação de modo que o mesmo processo de construção possa criar diferentes representações.

Destilando a intenção

Em vídeo: https://www.youtube.com/watch?v=2VwLvwsIu-8&list=PLbIBj8vQhvm0VY5YrMrafWaQY2EnJ3j8H&index=6

A intenção acima significa que:

  • O padrão sugere a separação do código que cria e o código que usa o objeto
  • Trata da criação de objetos complexos (complexos de verdade), como:
    • Objetos com construtores muito complexos
    • Objetos compostos de vários objetos (composite)
    • Objetos com algoritmo de criação complexo

Além disso, o padrão também:

  • Permite a criação de um objeto em etapas
  • Permite method chaining (encadeamento de métodos)
  • Permite que o objeto final varie em dados e tipo

Implementação

Vamos criar uma classe Pizza que pode ser personalizada com diferentes ingredientes. Usaremos o padrão Builder para construir a pizza de forma flexível.

1. Classe Pizza (Produto)

Esta é a classe que queremos construir. Ela representa uma pizza com vários atributos.

public class Pizza
{
    public string TipoMassa { get; set; }
    public string Molho { get; set; }
    public string Queijo { get; set; }
    public List<string> Ingredientes { get; set; } = new List<string>();

    public void Exibir()
    {
        Console.WriteLine($"Pizza com massa {TipoMassa}, molho {Molho} e queijo {Queijo}.");
        Console.WriteLine("Ingredientes:");
        foreach (var ingrediente in Ingredientes)
        {
            Console.WriteLine($"- {ingrediente}");
        }
    }
}

2. Interface IPizzaBuilder (Builder)

Define os métodos para construir cada parte da pizza.

public interface IPizzaBuilder
{
    void DefinirTipoMassa();
    void AdicionarMolho();
    void AdicionarQueijo();
    void AdicionarIngredientes();
    Pizza GetPizza();
}

3. Classe PizzaBuilder (Concrete Builder)

Implementa a interface IPizzaBuilder e define como a pizza será construída.

public class PizzaBuilder : IPizzaBuilder
{
    private Pizza _pizza = new Pizza();

    public void DefinirTipoMassa()
    {
        _pizza.TipoMassa = "fina";
    }

    public void AdicionarMolho()
    {
        _pizza.Molho = "tomate";
    }

    public void AdicionarQueijo()
    {
        _pizza.Queijo = "mozzarella";
    }

    public void AdicionarIngredientes()
    {
        _pizza.Ingredientes.Add("Pepperoni");
        _pizza.Ingredientes.Add("Cogumelos");
        _pizza.Ingredientes.Add("Azeitonas");
    }

    public Pizza GetPizza()
    {
        return _pizza;
    }
}

4. Classe PizzaDirector (Director)

Controla o processo de construção da pizza. Ele usa um IPizzaBuilder para construir a pizza passo a passo.

public class PizzaDirector
{
    private readonly IPizzaBuilder _pizzaBuilder;

    public PizzaDirector(IPizzaBuilder pizzaBuilder)
    {
        _pizzaBuilder = pizzaBuilder;
    }

    public void ConstruirPizza()
    {
        _pizzaBuilder.DefinirTipoMassa();
        _pizzaBuilder.AdicionarMolho();
        _pizzaBuilder.AdicionarQueijo();
        _pizzaBuilder.AdicionarIngredientes();
    }

    public Pizza GetPizza()
    {
        return _pizzaBuilder.GetPizza();
    }
}

5. Programa Principal

Aqui está como usar o Builder para criar uma pizza.

class Program
{
    static void Main(string[] args)
    {
        // Cria o Builder
        IPizzaBuilder pizzaBuilder = new PizzaBuilder();

        // Cria o Director e passa o Builder
        PizzaDirector pizzaDirector = new PizzaDirector(pizzaBuilder);

        // Constrói a pizza
        pizzaDirector.ConstruirPizza();

        // Obtém a pizza final
        Pizza pizza = pizzaDirector.GetPizza();

        // Exibe os detalhes da pizza
        pizza.Exibir();
    }
}

Saída Esperada

Ao executar o programa, a saída será:

Pizza com massa fina, molho tomate e queijo mozzarella.
Ingredientes:
- Pepperoni
- Cogumelos
- Azeitonas

Estrutura

Aplicabilidade

Use o Builder quando:

  • Use o Builder quando a criação do objeto se torna complexa
  • Use o Builder quando quiser que o código seja capaz de gerar diferentes representações do mesmo objeto

Consequências

O que é bom ou ruim no Builder:

Bom:

  • Separação de Responsabilidades: A lógica de construção do objeto é separada da representação do objeto
  • Flexibilidade: Você pode criar diferentes representações do mesmo objeto usando o mesmo processo de construção.
  • Código Mais Limpo: Ajuda na aplicação dos princípios SRP e OCP

Ruim:

  • O código final pode se tornar muito complexo
