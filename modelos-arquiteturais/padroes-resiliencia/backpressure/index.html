Backpressure (Contrapressão)

O Backpressure é um padrão de resiliência que controla o fluxo de dados entre produtores e consumidores para evitar sobrecarga. Se um sistema recebe mais requisições do que consegue processar, o Backpressure limita ou desacelera o fluxo de entrada para garantir estabilidade.
Tags:
  • Api Gateway
Categories:
  • Cloud

  3 minute read  

Como o Backpressure funciona?

O conceito se baseia no controle de fluxo entre um produtor (quem gera os dados) e um consumidor (quem processa os dados). Se o consumidor não consegue lidar com a demanda no ritmo que os dados chegam, ele sinaliza para o produtor reduzir a velocidade ou descartar dados excedentes.

Exemplo:
Imagine um servidor HTTP processando requisições de usuários. Se o banco de dados estiver sobrecarregado, o servidor pode:
1️⃣ Rejeitar novas requisições (código 429 - Too Many Requests).
2️⃣ Colocar requisições em uma fila para processar depois.
3️⃣ Reduzir a taxa de produção de novas requisições.

Estratégias de Implementação de Backpressure

1️⃣ Buffering (Fila de Espera)

Armazena temporariamente as requisições até que possam ser processadas. Se o buffer encher, pode descartar requisições antigas ou rejeitar novas.

Uso:

  • Filas como Kafka, RabbitMQ, AWS SQS permitem armazenar mensagens para processamento assíncrono.
  • Exemplo: Um sistema de pagamento pode enfileirar transações para processá-las de forma controlada.

2️⃣ Rate Limiting (Limitação de Taxa)

Reduz a taxa de requisições para não sobrecarregar o sistema.

Uso:

  • APIs limitam chamadas para evitar sobrecarga (exemplo: AWS API Gateway).
  • Sistemas de login bloqueiam múltiplas tentativas de senha para evitar ataques de força bruta.

3️⃣ Rejeição Inteligente (Early Backpressure)

Identifica sinais de sobrecarga cedo e rejeita requisições antes que o sistema colapse.

Uso:

  • Se um banco de dados começa a responder mais lentamente, o serviço que o acessa pode recusar requisições antes de atingir um estado crítico.

4️⃣ Propagação de Pressão (Feedback Loop)

Permite que sistemas informem uns aos outros quando estão sobrecarregados.

Uso:

  • Se um microserviço demora a processar requisições, ele pode sinalizar para serviços upstream reduzirem a taxa de envio de dados.
  • Protocolos como TCP Flow Control fazem isso ao ajustar a taxa de transmissão de pacotes conforme a capacidade da rede.

Exemplo de Implementação de Backpressure

Backpressure no Node.js (Streams)

const { Readable } = require('stream');

const producer = new Readable({
  read(size) {
    setTimeout(() => this.push("dados"), 1000); // Produz um dado por segundo
  }
});

producer.on('data', (chunk) => {
  console.log("Consumidor processando:", chunk);
  setTimeout(() => console.log("Processamento concluído"), 2000); // Consumidor leva 2s para processar
});

O consumidor processa mais devagar do que recebe dados, criando um gargalo.
Solução: Implementar controle de fluxo usando pause() e resume().

Backpressure no Kafka (Mensageria Assíncrona)

KafkaConsumer<String, String> consumer = new KafkaConsumer<>(properties);
consumer.subscribe(Collections.singletonList("meu-topico"));

while (true) {
    ConsumerRecords<String, String> records = consumer.poll(Duration.ofMillis(100));
    if (records.count() > 1000) {  // Se muitas mensagens chegarem, processa em lotes menores
        Thread.sleep(500); // Alivia a pressão
    }
    for (ConsumerRecord<String, String> record : records) {
        processMessage(record);
    }
}

Kafka permite pausar o consumo de mensagens se o sistema estiver sobrecarregado.

🆚 Backpressure vs. Outras Estratégias de Resiliência

PadrãoO que faz?Quando usar?
BackpressureControla o fluxo de entrada para evitar sobrecarga.Quando um sistema recebe mais dados do que pode processar.
Rate LimitingImpõe um limite fixo de requisições.Quando quer evitar que um usuário abuse do sistema.
Circuit BreakerBloqueia chamadas para serviços falhando repetidamente.Quando um serviço está instável e precisa de recuperação.
TimeoutCancela operações demoradas.Quando um serviço pode ficar lento e travar o sistema.

Melhor prática: Combine Backpressure + Rate Limiting + Circuit Breaker para sistemas altamente resilientes.

Conclusão

O Backpressure é um mecanismo essencial para evitar que sistemas entrem em colapso por sobrecarga. Ele atua reduzindo a taxa de entrada de dados quando o sistema está sob estresse, garantindo que o processamento ocorra de forma controlada.
