Complexidade de Algoritmos

A complexidade de um algoritmo mede o tempo e/ou o espaço que ele consome conforme o tamanho da entrada cresce. Isso ajuda a entender quão eficiente um algoritmo é para diferentes volumes de dados.
Categories:
  • Outros

  3 minute read  


1️⃣ Tipos de Complexidade

Complexidade de Tempo (Time Complexity)

  • Mede quantas operações o algoritmo executa em relação ao tamanho da entrada n.
  • Expressamos isso usando a notação Big-O.

Complexidade de Espaço (Space Complexity)

  • Mede quanto de memória um algoritmo usa, incluindo variáveis, estruturas e chamadas recursivas.
  • Também expressamos usando Big-O.


2️⃣ Principais Classes de Complexidade

Notação Big-ONomeExemplo
O(1)Tempo constanteAcessar um índice em um array.
O(log n)LogarítmicoBusca binária.
O(n)LinearPercorrer uma lista uma vez.
O(n log n)LinearítmicoMerge Sort, Quick Sort (melhor caso).
O(n²)QuadráticoBubble Sort, Selection Sort.
O(2ⁿ)ExponencialAlgoritmos de força bruta (ex.: Fibonacci recursivo).
O(n!)FatorialAlgoritmo de Caixeiro Viajante (TSP).


3️⃣ Exemplos Práticos em C#

✅ O(1) – Tempo Constante

Independente do tamanho da entrada, o tempo de execução não muda.

int RetornaPrimeiroElemento(int[] array) {
    return array[0]; // Sempre executa uma única operação
}
  • Entrada: [10, 20, 30, 40, 50]
  • Saída: 10
  • Complexidade: O(1) (tempo constante)

✅ O(n) – Tempo Linear

O tempo cresce proporcionalmente ao tamanho da entrada.

void ImprimirLista(int[] lista) {
    foreach (var item in lista) {
        Console.WriteLine(item);
    }
}
  • Entrada: [1, 2, 3, 4, 5]
  • Complexidade: O(n) (um loop que percorre toda a lista)

✅ O(log n) – Logarítmico (Busca Binária)

Dobra o desempenho reduzindo a entrada pela metade a cada passo.

int BuscaBinaria(int[] array, int alvo) {
    int inicio = 0, fim = array.Length - 1;

    while (inicio <= fim) {
        int meio = (inicio + fim) / 2;

        if (array[meio] == alvo) return meio;
        else if (array[meio] < alvo) inicio = meio + 1;
        else fim = meio - 1;
    }

    return -1; // Não encontrado
}
  • Entrada: [1, 3, 5, 7, 9, 11], buscando 7
  • Saída: Índice 3
  • Complexidade: O(log n) (corta pela metade a cada iteração)

✅ O(n²) – Tempo Quadrático (Bubble Sort)

Dois loops aninhados fazem a complexidade crescer exponencialmente.

void BubbleSort(int[] array) {
    for (int i = 0; i < array.Length - 1; i++) {
        for (int j = 0; j < array.Length - i - 1; j++) {
            if (array[j] > array[j + 1]) {
                int temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
            }
        }
    }
}
  • Entrada: [4, 2, 3, 1]
  • Saída: [1, 2, 3, 4]
  • Complexidade: O(n²) (dois loops aninhados)


4️⃣ Como Escolher o Melhor Algoritmo?

1️⃣ Se os dados são pequenos, qualquer algoritmo pode servir.
2️⃣ Se os dados crescem, prefira O(n log n) ou melhor.
3️⃣ Evite O(n²) ou pior, pois ficam lentos com grandes entradas.
4️⃣ Se possível, use algoritmos logarítmicos, como busca binária.


5️⃣ Conclusão

🔹 A complexidade ajuda a prever o desempenho antes da implementação.
🔹 Nem sempre o código mais rápido para um caso pequeno será eficiente para grandes entradas.
🔹 Big-O ajuda a escolher o melhor algoritmo para cada situação.
