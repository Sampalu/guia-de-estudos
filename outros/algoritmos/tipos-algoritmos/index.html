1️. Algoritmos de Busca

Usados para encontrar um elemento dentro de uma estrutura de dados.

  • Busca Linear (O(n))
    Percorre os elementos um por um até encontrar o valor desejado.

    int BuscaLinear(int[] array, int target)
{
    for (int i = 0; i < array.Length; i++)
    {
        if (array[i] == target)
            return i; // Retorna a posição do elemento encontrado
    }
    return -1; // Elemento não encontrado
}

    ✅ Funciona em qualquer estrutura de dados.
    ❌ Ineficiente para grandes conjuntos de dados.

  • Busca Binária (O(log n))
    Funciona em arrays ordenados e reduz a busca pela metade a cada iteração.

    int BuscaBinaria(int[] array, int target)
{
    int left = 0, right = array.Length - 1;

    while (left <= right)
    {
        int mid = (left + right) / 2;

        if (array[mid] == target) return mid;
        else if (array[mid] < target) left = mid + 1;
        else right = mid - 1;
    }

    return -1; // Elemento não encontrado
}

    ✅ Muito mais rápido que a busca linear para listas grandes.
    ❌ Requer que os dados estejam ordenados.

2️. Algoritmos de Ordenação

Usados para organizar os elementos em uma sequência ordenada.

  • Bubble Sort (O(n²))
    Compara elementos adjacentes e os troca se estiverem fora de ordem.

    void BubbleSort(int[] array)
{
    int n = array.Length;
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = 0; j < n - i - 1; j++)
        {
            if (array[j] > array[j + 1])
            {
                // Troca os elementos
                int temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
            }
        }
    }
}

    ✅ Fácil de entender e implementar.
    ❌ Muito ineficiente para listas grandes (O(n²)).

  • QuickSort (O(n log n))
    Escolhe um pivô, divide o array em duas partes e ordena recursivamente.

    void QuickSort(int[] array, int left, int right)
{
    if (left < right)
    {
        int pivot = Particiona(array, left, right);
        QuickSort(array, left, pivot - 1);
        QuickSort(array, pivot + 1, right);
    }
}

int Particiona(int[] array, int left, int right)
{
    int pivot = array[right];
    int i = left - 1;

    for (int j = left; j < right; j++)
    {
        if (array[j] < pivot)
        {
            i++;
            (array[i], array[j]) = (array[j], array[i]); // Troca
        }
    }

    (array[i + 1], array[right]) = (array[right], array[i + 1]);
    return i + 1;
}

    ✅ Muito eficiente para ordenar grandes quantidades de dados.
    ❌ Pode ter pior caso O(n²) se escolher pivô ruim.

3. Algoritmos Gulosos (Greedy)

Tomam decisões locais que parecem melhores no momento, tentando encontrar uma solução ótima global.

  • Problema da Mochila (Knapsack Problem)
    Imagine que você tem uma mochila com capacidade limitada e quer escolher os itens que cabem nela, maximizando o valor total.

    class Item
{
    public int Peso, Valor;
}

double MochilaGulosa(Item[] itens, int capacidade)
{
    Array.Sort(itens, (a, b) => (b.Valor / b.Peso).CompareTo(a.Valor / a.Peso)); // Ordena pelo melhor valor/peso

    double totalValor = 0;
    int pesoAtual = 0;

    foreach (var item in itens)
    {
        if (pesoAtual + item.Peso <= capacidade)
        {
            pesoAtual += item.Peso;
            totalValor += item.Valor;
        }
    }

    return totalValor;
}

    ✅ Funciona bem para alguns problemas.
    ❌ Não garante sempre a solução ótima.

4. Algoritmos Recursivos

Recursão é quando uma função chama a si mesma para resolver um problema menor.

  • Fatorial (O(n))
    O fatorial de um número ( n ) é ( n! = n \times (n-1)! ).
int Fatorial(int n)
{
    if (n == 0) return 1; // Caso base
    return n * Fatorial(n - 1); // Chamada recursiva
}

// Exemplo: Fatorial(5) → 5 * 4 * 3 * 2 * 1 = 120

✅ Fácil de entender, mas pode consumir muita memória se a recursão for muito profunda.

5. Algoritmos de Programação Dinâmica

Esses algoritmos resolvem problemas dividindo-os em subproblemas menores e armazenando os resultados para evitar cálculos repetidos.

  • Fibonacci com Memoization (O(n))
    A sequência de Fibonacci é: ( 0, 1, 1, 2, 3, 5, 8, 13, \dots ).
    O cálculo direto com recursão é ineficiente (O(2ⁿ)), mas podemos usar memoization para torná-lo O(n).
class FibonacciDP
{
    private Dictionary<int, long> memo = new Dictionary<int, long>();

    long Fibonacci(int n)
    {
        if (n <= 1) return n;
        if (memo.ContainsKey(n)) return memo[n];

        long result = Fibonacci(n - 1) + Fibonacci(n - 2);
        memo[n] = result; // Armazena resultado
        return result;
    }
}

// Exemplo: Fibonacci(50) → Calculado rapidamente

✅ Muito mais rápido do que a abordagem recursiva simples.

6. Algoritmos de Grafos

Grafos são estruturas que representam conexões entre elementos.

  • Busca em Largura (BFS) – O(V + E)
    A Busca em Largura (Breadth-First Search) explora todos os vizinhos antes de avançar.
void BFS(Dictionary<int, List<int>> graph, int start)
{
    Queue<int> queue = new Queue<int>();
    HashSet<int> visited = new HashSet<int>();

    queue.Enqueue(start);
    visited.Add(start);

    while (queue.Count > 0)
    {
        int node = queue.Dequeue();
        Console.WriteLine(node);

        foreach (var neighbor in graph[node])
        {
            if (!visited.Contains(neighbor))
            {
                visited.Add(neighbor);
                queue.Enqueue(neighbor);
            }
        }
    }
}

// Exemplo de grafo e chamada BFS
var graph = new Dictionary<int, List<int>>
{
    { 1, new List<int> { 2, 3 } },
    { 2, new List<int> { 4, 5 } },
    { 3, new List<int> { 6, 7 } },
    { 4, new List<int>() },
    { 5, new List<int>() },
    { 6, new List<int>() },
    { 7, new List<int>() }
};

BFS(graph, 1); // Saída: 1 → 2 → 3 → 4 → 5 → 6 → 7

✅ Útil para encontrar caminhos mais curtos e analisar conexões.

7. Algoritmos de Divisão e Conquista

Dividem o problema em subproblemas menores, resolvem cada um recursivamente e combinam os resultados.

  • Merge Sort (O(n log n))
    Esse algoritmo divide a lista em duas partes, ordena cada parte e depois mescla os resultados.
void MergeSort(int[] array, int left, int right)
{
    if (left < right)
    {
        int mid = (left + right) / 2;
        MergeSort(array, left, mid);
        MergeSort(array, mid + 1, right);
        Merge(array, left, mid, right);
    }
}

void Merge(int[] array, int left, int mid, int right)
{
    int[] leftArray = array[left..(mid + 1)];
    int[] rightArray = array[(mid + 1)..(right + 1)];

    int i = 0, j = 0, k = left;

    while (i < leftArray.Length && j < rightArray.Length)
    {
        array[k++] = (leftArray[i] <= rightArray[j]) ? leftArray[i++] : rightArray[j++];
    }

    while (i < leftArray.Length) array[k++] = leftArray[i++];
    while (j < rightArray.Length) array[k++] = rightArray[j++];
}

✅ Muito eficiente para ordenar grandes quantidades de dados.

8. Algoritmos de Caminho Mínimo

Usados para encontrar o caminho mais curto entre dois pontos em um grafo.

  • Dijkstra (O((V + E) log V))
    Esse algoritmo encontra a menor distância de um nó inicial para todos os outros.
void Dijkstra(Dictionary<int, List<(int, int)>> graph, int start)
{
    var distances = new Dictionary<int, int>();
    var priorityQueue = new SortedSet<(int dist, int node)>();

    foreach (var node in graph.Keys) distances[node] = int.MaxValue;
    distances[start] = 0;
    priorityQueue.Add((0, start));

    while (priorityQueue.Count > 0)
    {
        var (dist, node) = priorityQueue.Min;
        priorityQueue.Remove(priorityQueue.Min);

        foreach (var (neighbor, weight) in graph[node])
        {
            int newDist = dist + weight;
            if (newDist < distances[neighbor])
            {
                priorityQueue.Remove((distances[neighbor], neighbor));
                distances[neighbor] = newDist;
                priorityQueue.Add((newDist, neighbor));
            }
        }
    }

    foreach (var (node, distance) in distances)
    {
        Console.WriteLine($"Distância até {node}: {distance}");
    }
}

// Exemplo de grafo e chamada de Dijkstra
var graph = new Dictionary<int, List<(int, int)>>
{
    { 1, new List<(int, int)> { (2, 4), (3, 1) } },
    { 2, new List<(int, int)> { (4, 1) } },
    { 3, new List<(int, int)> { (2, 2), (4, 5) } },
    { 4, new List<(int, int)>() }
};

Dijkstra(graph, 1);

✅ Usado em GPS, redes de computadores, IA para jogos, etc.

Conclusão

Os algoritmos são a base da programação e podem ser otimizados dependendo do problema. Existem muitos tipos de algoritmos, cada um adequado para diferentes situações:

  • Busca Linear é simples, mas lenta (O(n)).
  • Busca Binária é eficiente, mas exige dados ordenados (O(log n)).
  • Bubble Sort é ineficiente (O(n²)), enquanto QuickSort é muito rápido (O(n log n)).
  • Algoritmos Gulosos resolvem problemas rapidamente, mas podem não ser perfeitos.
  • Recursivos – Simples, mas podem ser ineficientes.
  • Programação Dinâmica – Evita cálculos repetidos, tornando algoritmos eficientes.
  • Grafos (BFS, Dijkstra) – Para redes, caminhos mínimos e conexões.
  • Ordenação (Merge Sort, QuickSort) – Para organizar dados de maneira eficiente.
  • Divisão e Conquista – Técnica poderosa para muitos problemas.

Exemplo do “Greedy Algorithm”

O nome original é “Greedy Algorithm”, e “algoritmo guloso” é a tradução comum usada em português. Ele recebe esse nome porque sempre toma a decisão que parece melhor no momento, sem se preocupar com o futuro.

Troco com Menor Número de Moedas (O(n))

Dado um valor e um conjunto de moedas disponíveis, queremos encontrar a quantidade mínima de moedas necessárias para formar esse valor.

Exemplo com moedas de: 1, 5, 10, 25, 50 centavos e 1 real

Se quisermos formar R$ 2,37, o algoritmo deve escolher as maiores moedas primeiro.

void TrocoGuloso(int valor, int[] moedas)
{
    Array.Sort(moedas);
    Array.Reverse(moedas); // Ordena para pegar as maiores primeiro

    Dictionary<int, int> resultado = new Dictionary<int, int>();

    foreach (var moeda in moedas)
    {
        if (valor >= moeda)
        {
            int qtd = valor / moeda;
            resultado[moeda] = qtd;
            valor %= moeda;
        }
    }

    // Exibir resultado
    foreach (var (moeda, qtd) in resultado)
    {
        Console.WriteLine($"{qtd} moeda(s) de {moeda} centavo(s)");
    }
}

// Exemplo de uso
int valor = 237; // R$ 2,37 em centavos
int[] moedas = { 1, 5, 10, 25, 50, 100 }; // Valores em centavos

TrocoGuloso(valor, moedas);

Saída:

2 moeda(s) de 100 centavo(s) (1 real)
1 moeda(s) de 25 centavo(s)
1 moeda(s) de 10 centavo(s)
2 moeda(s) de 1 centavo(s)

✅ Rápido e fácil de implementar.
❌ Não funciona para todos os casos! Se tivermos moedas de 4 e 3 centavos e quisermos formar 6 centavos, o algoritmo escolheria 4 + 1 + 1 (três moedas), em vez de 3 + 3 (duas moedas).

Esse algoritmo guloso funciona bem quando:

  • O problema tem uma propriedade gulosa → A melhor escolha local sempre leva à melhor solução global.
  • Ele pode ser usado para otimizar problemas como roteamento de redes, compressão de dados (Huffman) e seleção de atividades.
