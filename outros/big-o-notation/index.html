Big-O Notation

A notação O (também chamada de O-grande, ou Big-O Notation) é usada para descrever a complexidade de algoritmos, ou seja, como o tempo de execução cresce conforme o tamanho da entrada aumenta.
Categories:
  • Outros

  2 minute read  

📌 O que significa O(n)?

A notação O(n) significa que o tempo de execução do algoritmo cresce linearmente em relação ao tamanho da entrada. Se o tamanho da entrada for dobrado, o tempo de execução também dobra aproximadamente.

🚀 Exemplos de O(n) em C#

1️⃣ Percorrendo um array (Complexidade O(n))

Um exemplo clássico de O(n) é um loop que percorre um array:

void PrintElements(int[] array)
{
    foreach (var item in array)
    {
        Console.WriteLine(item); // Executado 'n' vezes
    }
}

✅ Se o array tiver 10 elementos, o loop roda 10 vezes.
✅ Se o array tiver 1.000 elementos, o loop roda 1.000 vezes.
📌 Como o número de operações cresce proporcionalmente ao tamanho da entrada, temos O(n).

2️⃣ Encontrando um elemento (Busca Linear - O(n))

A busca linear em um array também tem complexidade O(n), pois no pior caso precisa percorrer todos os elementos.

bool Contains(int[] array, int target)
{
    foreach (var item in array)
    {
        if (item == target)
            return true; // Pode parar antes, mas no pior caso percorre tudo
    }
    return false;
}

✅ Se o elemento estiver no início, pode ser rápido.
✅ Se o elemento não estiver no array, percorre tudo.
📌 No pior caso, a função faz n comparações, então a complexidade é O(n).

3️⃣ Função com múltiplos loops independentes (O(n))

Se tivermos dois loops independentes, ainda é O(n):

void ProcessArray(int[] array)
{
    foreach (var item in array)
    {
        Console.WriteLine(item); // O(n)
    }

    foreach (var item in array)
    {
        Console.WriteLine(item * 2); // O(n)
    }
}

📌 Aqui há dois loops O(n) independentes, mas a complexidade não é O(2n), pois O-grande ignora constantes. O(2n) é simplificado para O(n).

🚨 O que NÃO é O(n)?

🔹 O(1) – Tempo constante

int GetFirstElement(int[] array)
{
    return array[0]; // Sempre O(1), independente do tamanho do array
}

🔹 O(n²) – Tempo quadrático (loops aninhados)

void PrintPairs(int[] array)
{
    for (int i = 0; i < array.Length; i++)
    {
        for (int j = 0; j < array.Length; j++)
        {
            Console.WriteLine($"({array[i]}, {array[j]})");
        }
    }
}

📌 Aqui temos dois loops aninhados, então a complexidade é O(n²).

📌 Resumo

  • O(1) → Tempo constante, independente do tamanho da entrada.
  • O(n) → Tempo cresce linearmente com a entrada.
  • O(n²) → Tempo cresce quadraticamente (ex: loops aninhados).

A complexidade O(n) é comum em buscas lineares, processamento de listas e qualquer função que percorre um conjunto de dados uma única vez.
